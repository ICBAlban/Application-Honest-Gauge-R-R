# Application for Determining Repeatability and Reproducibility in an Honest Gauge R&R Study
This program is an application designed to perform an honest Gauge R&R. The explanations and functionality of the application can be found at the following address:

https://onlinelibrary.wiley.com/doi/full/10.1002/qre.3752

## Content
An executable version is available in the Software/dist/main.exe folder. 
Alternatively, the source code written in Python is available in the Python Code folder. 

## Attention
This program and the Python source code is not being kept up to date. 

## Requirement
This code is written in Python 3.12, and the module required for its operation is numpy version 1.26.
